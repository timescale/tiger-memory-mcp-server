# Tiger Memory

A tiger prowls through neural streams,
Collecting wisdom, storing dreams,
With Model Context Protocol's might,
It captures knowledge, holds it tight.

In PostgreSQL's database deep,
A memory that LLMs keep,
From REST endpoints to MCP tools,
These structured data-bearing jewels.

TypeScript precise, zod-validated,
Information well-curated,
Kubernetes-bound, Helm-configured,
For AI systems, well-engineered.

Each tool, a synapse firing true,
To store what models learn and do,
Through inspector's watchful eye,
Tiger Memory learns to fly.

Focused, simple, yet profound,
In cloud and cluster, it is found,
A guardian of context long,
Tiger Memory, forever strong.
